# 🌐 Проектная работа: Сетевая инфраструктура организации

## 🎯 Цель работы
Разработать и настроить сетевую инфраструктуру организации, включающей 2 ЦОДа (основной + резервный) и 2 офисные площадки (МСК, СПБ).

---

## 🏗️ Архитектура сети

| Уровень | Описание | Устройства |
|---------|----------|------------|
| **ЦОД-1** | Основная площадка с серверами | DC1-R1, DC1-R2, DC1-ACC |
| **ЦОД-2** | Резервная площадка с серверами | DC2-R1, DC2-R2, DC2-ACC |
| **Офис МСК** | Филиал в Москве | MSK-R1, MSK-R2, MSK-ACC1, MSK-ACC2 |
| **Офис СПБ** | Филиал в Санкт-Петербурге | SPB-R1, SPB-R2, SPB-ACC1, SPB-ACC2 |

## 🛠 Используемые технологии

| Технология | Назначение |
|------------|------------|
| **EIGRP** | Внутренняя маршрутизация между Core |
| **BGP** | Маршрутизация между филиалами и ЦОД через MPLS |
| **MPLS L3VPN** | L3VPN от провайдера |
| **HSRP** | Резервирование шлюзов VLAN |
| **BFD** | Быстрое обнаружение отказа каналов |
| **LACP / vPC / MLAG** | Агрегация uplink-портов |
| **VLAN** | Изоляция трафика (Users, Voice, CCTV, Servers) |
| **DHCP Snooping** | Защита от несанкционированных DHCP-серверов |
| **SNMPv3 / Syslog / NetFlow** | Мониторинг и управление |
