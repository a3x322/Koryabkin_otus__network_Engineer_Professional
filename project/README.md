# 🌐 Проектная работа: Сетевая инфраструктура организации

---

## 📋 Текст задания

Разработать и настроить сетевую инфраструктуру организации, включающей:

- **2 ЦОДа** (основной + резервный)
- **2 офисные площадки** (Москва, Санкт-Петербург)

### Требования:

1. Разработать **IP-план** для всех сегментов сети.
2. Обеспечить **резервирование** на всех уровнях:
   - 2 Core-роутера в каждом ЦОД
   - 2 Access-коммутатора в каждом офисе
   - Резервные линки между ЦОД (тёмная оптика)
3. Настроить **EIGRP** для внутренней маршрутизации.
4. Настроить **BGP** для обмена маршрутами с провайдером (MPLS L3VPN).
5. Настроить **HSRP** для резервирования шлюзов VLAN.
6. Настроить **BFD** для быстрого обнаружения отказа линков.
7. Настроить **LACP** для агрегации uplink-портов.
8. Обеспечить **мониторинг** и управление (SNMPv3, Syslog, NetFlow).
9. Оформить **документацию** в Git (README, адресация, схема, конфиги).

Разработать и настроить сетевую инфраструктуру для:

- 2 ЦОД (основной и резервный)

- MPLS L3VPN от провайдера
- Тёмная оптика между ЦОД

- HSRP, LACP, BFD, EIGRP, BGP
- Мониторинг и управление (SNMPv3, Syslog, NetFlow)

## 🏗️ Архитектура сети

| Уровень | Описание | Устройства |
|---------|----------|------------|
| **ЦОД-1** | Основная площадка с серверами | DC1-R1, DC1-R2, DC1-ACC |
| **ЦОД-2** | Резервная площадка с серверами | DC2-R1, DC2-R2, DC2-ACC |
| **Офис МСК** | Филиал в Москве | MSK-R1, MSK-R2, MSK-ACC1, MSK-ACC2 |
| **Офис СПБ** | Филиал в Санкт-Петербурге | SPB-R1, SPB-R2, SPB-ACC1, SPB-ACC2 |

## 🛠 Используемые технологии

| Технология | Назначение |
|------------|------------|
| **EIGRP** | Внутренняя маршрутизация |
| **BGP** | Маршрутизация между филиалами и провайдером |
| **MPLS L3VPN** | Транзит от провайдера |
| **HSRP** | Резервирование шлюзов |
| **BFD** | Быстрое обнаружение отказа |
| **LACP / vPC** | Агрегация uplink-портов |
| **VLAN** | Изоляция трафика |
| **DHCP Snooping** | Защита от подмены DHCP |
| **SNMPv3 / Syslog / NetFlow** | Мониторинг |
