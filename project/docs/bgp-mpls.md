# BGP и MPLS L3VPN

## BGP

### Автономные системы (AS)

| AS | Описание |
|----|----------|
| 64500 | Провайдер (MPLS L3VPN) |
| 65001 | ЦОД-1 |
| 65002 | ЦОД-2 |
| 65100 | Офис МСК |
| 65200 | Офис СПБ |

---

### Особенности BGP

- **eBGP** между клиентами и провайдером.
- **BFD** включён для всех соседей.
- **Анонсируются суммарные сети** (/16) для каждого сегмента.
- **VRF** изолирует клиентский трафик от трафика управления.

---

### Пример настройки (MSK-R1)

```cisco
router bgp 65100
 bgp log-neighbor-changes
 address-family ipv4 vrf CORP-MPLS
  network 10.10.0.0 mask 255.255.0.0
  neighbor 172.31.10.1 remote-as 64500
  neighbor 172.31.10.1 activate
  neighbor 172.31.10.1 fall-over bfd
  neighbor 172.31.10.3 remote-as 64500
  neighbor 172.31.10.3 activate
  neighbor 172.31.10.3 fall-over bfd
 exit-address-family
```

## MPLS L3VPN

### Параметры VRF

| Параметр | Значение |
|----------|----------|
| VRF | CORP-MPLS |
| RD (ЦОД-1) | 65001:1 |
| RD (ЦОД-2) | 65002:1 |
| RD (МСК) | 65100:1 |
| RD (СПБ) | 65200:1 |
| RT (импорт/экспорт) | 65000:100 |

---

### Как работает MPLS L3VPN

1. **CE** (клиентский роутер) анонсирует маршруты в BGP.
2. **PE** (провайдер) помечает их **RD** и **RT**.
3. Маршруты передаются через **MP-BGP** между PE.
4. На стороне получателя маршруты импортируются в нужный VRF.

---

### Преимущества MPLS L3VPN

- Полная изоляция трафика между клиентами.
- Масштабируемость (поддержка тысяч VRF).
- Поддержка IPv4 и IPv6.
- Гибкость в управлении маршрутами (RT, RD).
