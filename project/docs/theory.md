# 📚 Теория по проекту

## EIGRP
Используется для внутренней маршрутизации между Core-роутерами ЦОД и офисов.
- AS: 100
- BFD включён для быстрого обнаружения отказа

## BGP
Используется для обмена маршрутами с провайдером через MPLS L3VPN.
- AS: 65001 (ЦОД-1), 65002 (ЦОД-2), 65100 (МСК), 65200 (СПБ)
- Провайдер: AS 64500
- Активирована BFD для ускорения переключения

## HSRP
Резервирование шлюзов для всех VLAN.
- VIP: .1
- R1: .2 (priority 115)
- R2: .3 (priority 100)

## BFD
Обнаружение отказа каналов за < 50 мс.
- Интервал: 50 мс
- Множитель: 3

## LACP
Агрегация uplink-портов Core → Access.
- Режим: active
- Port-channel: 10 (Core), 1 (Access)

## Мониторинг
- SNMPv3 с шифрованием
- Syslog
- NetFlow
