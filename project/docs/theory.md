# 📚 Теория по проекту

## Обзор технологий

| Технология | Назначение |
|------------|------------|
| **EIGRP** | Внутренняя маршрутизация между Core-роутерами |
| **BGP + MPLS L3VPN** | Обмен маршрутами с провайдером |
| **HSRP** | Резервирование шлюзов VLAN |
| **BFD** | Быстрое обнаружение отказа каналов |
| **LACP** | Агрегация uplink-портов |
| **SNMPv3 / Syslog / NetFlow** | Мониторинг и управление |
